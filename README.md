# DHIKI

DHIKI est une plateforme gratuite de bien-être mental, née à Lomé et pensée pour les jeunes au Togo. Elle offre un espace calme, anonyme et sans jugement pour mieux comprendre ce que l'on ressent : des rubriques thématiques (anxiété, sommeil, confiance en soi, relations, deuil…), des exercices guidés, un parcours « Faire le point » et la possibilité de poser une question, publique ou confidentielle, à un professionnel.

Le projet se compose d'un site public en React, d'une API Node.js reliée à une base PostgreSQL et, à terme, d'un espace d'administration pour l'équipe. DHIKI ne remplace ni une consultation ni les services d'urgence : il aide à mettre des mots sur ses émotions et oriente vers le bon soutien.
